# Video Demo Script (2 minutes)

## Equipment Needed:
- Loom.com (free screen recorder) OR QuickTime (Mac)
- Your deployed URL OR localhost:5173
- Sample PDF (your resume, article, etc.)

## Script:

### [0:00-0:15] Introduction
"Hi! I'm [Name]. I built a RAG chatbot that can upload documents and answer questions about them in real-time. Let me show you."

### [0:15-0:45] Upload Demo
- Click "Upload Document"
- Select a PDF (e.g., your resume)
- Show: "File uploaded! 42 chunks indexed."
- Say: "The system breaks documents into chunks and creates vector embeddings for semantic search."

### [0:45-1:15] Chat Demo
- Type: "What are the main topics in this document?"
- Show: AI streaming response word-by-word
- Say: "Notice how it streams in real-time using Server-Sent Events, with sub-100ms latency."
- Point out: Source attribution at bottom

### [1:15-1:30] Mobile Demo
- Open DevTools, toggle device mode
- Show: Responsive layout on iPhone
- Say: "Fully responsive, works on any device."

### [1:30-1:50] Tech Overview
- Show GitHub repo briefly
- Say: "Built with FastAPI backend, React frontend, FAISS vector database, and Google Gemini AI."
- Mention: "20+ well-organized commits, Docker deployment, comprehensive docs."

### [1:50-2:00] Close
- Say: "Check out the code on GitHub and try the live demo yourself!"
- Show: GitHub URL and live demo URL

## Recording Tips:
- Clean browser (close extra tabs)
- Zoom to 110% for better visibility
- Speak clearly and enthusiastically
- Keep it under 2 minutes
- No "umms" - edit them out

## Upload To:
- YouTube (public or unlisted)
- Loom (get shareable link)
- LinkedIn (native video)

## Add Link To:
- README.md
- LinkedIn post
- Resume (QR code optional)
